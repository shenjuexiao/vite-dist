项目简介

本项目演示 Vite 多页面（MPA）架构：每个页面拥有独立 HTML 入口， 页眉与页脚通过 layout.js 统一注入，实现一次编写、多处复用。

目录结构

project/
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── header.js
│   ├── footer.js
│   ├── layout.js
│   ├── style.css
│   └── main.js
└── pages/
    ├── tools.html / tools.js
    ├── docs.html  / docs.js
    └── about.html / about.js

开发命令

npm install
npm run dev      # 本地开发
npm run build    # 生产构建
npm run preview  # 预览构建结果
