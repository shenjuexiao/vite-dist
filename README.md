# Vite 多页面工具集

## 🚀 项目

[shenjuexiao/vite-multi](https://github.com/shenjuexiao/vite-multi)

## 😀 简介

🪟 基于 Vite 的多页面应用（MPA），页眉、页脚拆分独立模块，通过 `layout.js` 统一组合。

## 📁 目录

- `src/main.js` — 首页 JS
- `src/header.js` — 页头组件
- `src/footer.js` — 页脚组件
- `src/layout.js` — 布局组合器
- `src/style.css` — 全局样式
- `pages/` — 各子页面 HTML + JS

## 💻 开发

```bash
npm install
npm run dev
```
